# Engrove Audio Tools & Audio Lab

This repository collects public reports about incorrect or missing equipment data in [Engrove Audio Tools](https://engroveaudio.com/). To report a correction or suggest equipment, use the [issue forms](https://github.com/Engrove/Issues/issues/new/choose) and include a source where possible.

It also shares design files and audio measurement signals. [Browse the published objects](objekts/) or explore the turntable in [Engrove Audio Lab](https://lab.engroveaudio.com/).
