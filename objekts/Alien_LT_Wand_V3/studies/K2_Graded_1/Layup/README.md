# Alien LT · K2 Graded 1 carbon ply kit

This prototype package contains the nominal carbon plies for the left (W01) and right (W02) wand halves. The K2 wall uses the R3 outer mould with local changes to the fibre stack. The STEP represents the pieces after machining. The workshop links these components to their dry cut pieces, shows the fibre directions and supplies full-size cut and placement sheets.

- [Wand_K2_Graded_1_Ply_Kit.step.xz](Wand_K2_Graded_1_Ply_Kit.step.xz) — decompress the XZ file and open the STEP in a CAD reader with support for AP242 tessellated solids. Each component retains its ply and hand ID. The CAD unit is mm.
- [Wand_K2_Graded_1_Ply_Kit.pseudo](Wand_K2_Graded_1_Ply_Kit.pseudo) — coordinate system, material stock, stacking and transition rules.
- [Interactive layup and workshop sheets](https://lab.engroveaudio.com/tonearm/layup/) · [tonearm data and calculated results](https://lab.engroveaudio.com/tonearm/data/) · [complete K2 study assembly](https://github.com/Engrove/Issues/tree/main/objekts/Alien_LT_Wand_V3/studies/K2_Graded_1).

Follow the mould-side orientation printed on each sheet. Inspect the two hands separately and dry-fit the 0° ribbon over the pivot saddle before wetting it out. The mounted FE report uses nominal laminate material cards. Physical fibre angles, cured gauge and assembled response require measurement on the actual layup.
