# Alien LT Wand V3 R1

Wand_V3_R1.step is the 23-solid wand and adjustable counterweight design study. Open the STEP in a CAD viewer using millimetres. The two external trim tubes follow the wand’s X axis. The four-sector counterweight moves vertically in the fixed sleeve.

Wand_V3_R1.pseudo describes the part geometry, assembly order, coordinates and nominal adjustments. It can be read as plain UTF-8 text alongside the STEP.
